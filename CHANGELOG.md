# Changelog

## v1.0.0 — Initial Release

- First-run setup wizard with password, port, and permissions config
- Password protection with bcrypt hashing and session cookies
- Web UI with file browsing, download, upload, delete, and ZIP support
- Live file search in the browser
- Drag & drop file upload
- JSON API endpoint at `/api/files`
- Responsive mobile-friendly design
- Graceful shutdown on Ctrl+C
- Cross-platform: Windows, Linux, macOS (amd64 + arm64)
- Beautiful CLI with lipgloss styling and ASCII art banner
